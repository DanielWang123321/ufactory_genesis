# Trajectory-controlled simulation examples

[中文](README_zh.md) · [Examples guide](../README.md)

Multi-robot Genesis physics simulation, offline trajectory/collision preflight (`dry-run`), controller simulation (`sdk-sim`), and guarded hardware execution (`real`). Install the package and run commands from the repository root as described in [Prerequisites](../README.md#prerequisites).

1. **[Pick-place](pick_place/README.md)**: grasp, lift, transfer, and place objects across `xarm5`, `xarm6`, `xarm7`, `uf850`, and `lite6` (Gripper G2, Bio Gripper G2 microplate, and Lite6 Gripper).
2. **[Packaging showcase](packaging/README.md)**: YAML-configured multi-robot box packing with natural-drop contact simulation and safety preflight.

For policy-trained reinforcement learning tasks, see the [RL index](../rl/README.md).

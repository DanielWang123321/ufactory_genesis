# 轨迹控制物理仿真示例

[English](README.md) · [示例指南](../README_zh.md)

多机型 Genesis 物理接触仿真、离线轨迹与碰撞预检（`dry-run`）、控制器虚拟仿真（`sdk-sim`）及受控真机执行（`real`）。安装方式及运行目录见[前置条件](../README_zh.md#前置条件)。

1. **[抓放仿真](pick_place/README_zh.md)**：覆盖 `xarm5`、`xarm6`、`xarm7`、`uf850`、`lite6` 的物体抓取、搬运与放置（含 Gripper G2、Bio Gripper G2 微孔板与 Lite6 Gripper）。
2. **[装箱展示仿真](packaging/README_zh.md)**：基于 YAML 配置的多机型装箱轨迹控制、自然下落接触仿真与安全预检。

策略训练与强化学习示例见 [RL 索引](../rl/README_zh.md)。

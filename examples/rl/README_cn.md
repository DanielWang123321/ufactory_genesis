# 强化学习示例

按以下顺序从易到难运行示例。所有流程均在仿真中执行，请在项目根目录通过模块方式运行指令。

仓库不附带或提交策略权重、检查点，用户自行训练。训练产物保存在 Git 忽略的 `outputs/rl/` 下。

1. **[Reach：目标到达](reach/README_cn.md)**：不装夹爪，让 xArm 6 末端到达目标点。成功距离严格小于 **5 mm**，默认训练种子 7。指南提供训练、检查点筛选、验收和 GLB 实时推理指令，仓库不附带权重。
2. **[Pick & Place：桌面抓放](pick_place/README_cn.md)**：使用 xArm6 + Gripper G2 抓取、抬升并搬运方块，在桌面目标位置放下、松爪。当前示例采用固定布局，指南提供训练和推理指令。
3. **装箱：待实现**：将物体放入箱内，增加箱体几何与接触约束。RL 环境及训练、推理入口尚未实现。

现有[装箱展示](../README_zh.md#装箱展示仿真)采用轨迹控制。

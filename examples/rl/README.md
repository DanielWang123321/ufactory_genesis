# Reinforcement-learning examples

The public v0.2.11 RL surface contains one deliberately narrow example:
[xArm6 + Gripper G2 fixed-layout pick-place](pick_place/README.md). It includes a
canonical recipe, a deterministic 512-episode scenario bank, and a validated
`model_199.pt` checkpoint bundle.

Run every entry as a module from the repository root. The example supports Linux
with an NVIDIA GPU only. It does not provide a real-robot policy executor.
